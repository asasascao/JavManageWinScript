# JavManageWinScript
方便手动本地管理Jav而使用的win操作脚本

copy_file_keep_dir_scriptpath_with_traget.bat 复制文件 保存当前目录结构 脚本所在地址使用 
                                                  参数 目标地址
                                                  
copy_file_keep_dir_with_sorce_traget.bat 复制文件 保存当前目录结构 
                                                  参数 源地址 目标地址
                                                  
copy_file_keep_dir_workarea_with_traget.bat 复制文件 保存当前目录结构 当前工作目录‌（cmd前缀）使用 
                                                  参数 目标地址
                                                  
remove_file_keep_dir.bat 删除文件 保存当前目录结构 
                                                  文件夹拖动到bat上使用
                                                  
rename.bat 重命名脚本 把不规则的jav名称修改成类似于HJMO-731.MP4这样的格式

重启QuickLook.bat 当QuickLook死机时重启QuickLook的快速脚本，也可用于重启其他软件 需进入修改软件位置


CreateStartMenuLink.bat 创建开始菜单快捷方式 
                        将该 CreateStartMenuLink.bat 文件复制到一个合理文件夹内中 比如 E:\ProgramFile\Program\批处理脚本
                        按下 Win + R，输入 shell:sendto 回车 在打开的文件夹中右键新建快捷方式，将bat路径填入 比如 E:\ProgramFile\Program\批处理脚本\CreateStartMenuLink.bat 下一步
                        填入创建开始菜单快捷方式后下一步完成即可
